# ФОРК ИТ — Прототип v2
**Оптимизатор простоев горной техники** · Студия Луч

## Запуск

```bash
npm install
npm run dev
```

Открыть: **http://localhost:3000**

## Что нового в v2
- 🌙 Тёмный режим (по умолчанию) + ☀️ Светлый режим
- Переключение темой — кнопка в шапке (🌙/☀️)
- Переработанный UI: меньше визуального шума, чище типографика
- Все цвета через CSS-переменные — плавные переходы при смене темы
- Карта адаптируется под обе темы
