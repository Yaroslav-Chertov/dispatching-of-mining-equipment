# ФОРК ИТ — Прототип редизайна
**Оптимизатор простоев горной техники**

Прототип главной страницы — Студия Луч, пресейл-концепт.

---

## Запуск

```bash
npm install
npm run dev
```

Открыть в браузере: **http://localhost:3000**

---

## Стек
- Next.js 15 (App Router)
- TypeScript
- SCSS Modules

## Брендинг клиента
- Оранжевый: `#F65318` (ФОРК ИТ brand orange)
- Антрацит: `#2A2A2A`
- Шрифт: Golos Text (основной)
